📖 Panduan

Akses Pengguna

  • Manajer — akses penuh (Aset Tetap, Edit Barang, Laporan, Riwayat, koreksi stok dari Stok On Hand).
  • Karyawan — Stok, Pembelian, Penjualan, Stok On Hand (observasi saja), Keuangan, Panduan.

Pembelian

  • Stok Awal — register barang baru. Jumlah boleh 0 untuk registrasi awal.
  • Dibeli — menambah stok barang yang sudah terdaftar.

Stok On Hand (Daerah)

Satu tempat untuk input stok fisik. Ada dua mode:

  • Mode observasi (checkbox tidak dicentang) — hanya mencatat, tidak mengubah stok sistem. Cocok untuk monitoring rutin.
  • Mode koreksi (checkbox "Sesuaikan stok sistem" dicentang, khusus manajer) — mengoreksi stok sistem dan membuat jurnal penyesuaian otomatis:
    • Fisik < sistem: Beban Persediaan (D) / Persediaan (K)
    • Fisik > sistem: Persediaan (D) / Beban Persediaan (K)

Edit Barang

Untuk mengubah nama, kategori, satuan, atau harga jual. Perubahan nama barang otomatis ikut mengubah riwayat terkait agar laporan tetap sinkron.

Rekap Barang

Stok Akhir (Pusat) = Stok Awal + Pembelian − Penjualan. Dibandingkan dengan Stok On Hand (Daerah). Selisih positif artinya sistem lebih tinggi dari fisik (potensi kehilangan), selisih negatif artinya fisik lebih tinggi dari sistem.

HPP Metode FIFO — barang yang paling awal masuk dianggap paling awal terjual.
